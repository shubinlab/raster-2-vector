# raster-2-vector v1.0

Новый Agent Skill для векторизации и типографической реконструкции логотипов. Основа: прежний `precision-typography-vectorizer`, переписанный с поддержкой сохранённых SVG-контуров, геометрического упрощения, непрерывности касательных и жёсткой автоматической проверки по исходному растру.

## Установка в Codex

Распакуйте архив так, чтобы файл `SKILL.md` лежал по пути `~/.agents/skills/raster-2-vector/SKILL.md` (или в `.agents/skills/raster-2-vector/` проекта). Не нужно копировать шрифты, картинки исходных логотипов или большие тестовые данные. Установите зависимости: `pip install -r requirements.txt`. Для трассировки требуется системная библиотека `libpotrace` (Linux: `sudo apt install libpotrace0`). `refine` и `audit` работают без Potrace.

Проверка: `python scripts/r2v.py doctor` и `python -m unittest discover -s tests -v`.

### Пример

```bash
python scripts/r2v.py refine existing.svg --source original.png --out wordmark.svg --threshold 180 --polarity light --min-iou 0.95
```

Получатся `wordmark.svg`, `wordmark.png`, `wordmark_overlay.png`. Сохранённый SVG прозрачный, PNG выводится на фоне оригинального изображения. Программа печатает JSON с IoU, геометрией и топологией. Если качество не проходит порог, инструмент не выдаёт результат как успешный.

## Отличия от предыдущей версии

- Вместо повторной трассировки можно **упрощать существующий хороший SVG**.
- Прямые и кривые обрабатываются по разным правилам. Кривые объединяются только с малым отклонением и согласованными касательными.
- Обнаруживается очевидная эллиптическая геометрия. Это сокращает размер кольцевых букв.
- Скрипт отсекает кандидатов по геометрии до дорогой растеризации и ограничивает число проверок.
- Контроль не только общего IoU, но и числа компонентов/просветов и отклонения границы.
- Ровно три визуальных результата на каждую работу. Логи измерений остаются в консоли/внутри процесса.
- Право отступить от IoU 95% ради эстетики требует явного решения, метрик и сравнения.

Код предназначен для плоских одноцветных логотипов. Полный автоматический анализ шрифтового строя он **не выполняет**: оптическое качество требует отдельной экспертной проверки.
